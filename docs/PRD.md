# Ringkasan kebutuhan

Website PT Elevate Apparel Karya Mandiri menampilkan identitas bisnis, katalog pakaian custom, detail produk, proses produksi, dan formulir konsultasi. Admin mengelola kategori, produk, inquiry, dan profil bisnis. Tidak ada keranjang, checkout, atau pembayaran karena harga produksi akhir memerlukan konsultasi spesifikasi. Target visual: editorial streetwear dengan palet ink black, electric lime, warm cream, dan signal orange. Acceptance criteria teknis dirangkum dalam README dan diuji pada `tests/Feature/ElevateFeatureTest.php`.
